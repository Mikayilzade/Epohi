# Эпохи: Люди — чек-лист перемещения и производительности

Статус: рабочий конечный объём блока. После выполнения пункты отмечаются и блок закрывается без дополнительной полировки.

## 1. Производительность

- [x] У маршрутов устранён цикл «наблюдатель → перерисовка → наблюдатель»; слой пути меняется только при изменении маршрута.
- [x] Убрана постоянная анимация каждой водной клетки и тяжёлый blur на ресурсных карточках.
- [x] В покое нет таймера, кадрового цикла или глобальной подмены MutationObserver, постоянно перерисовывающих карту.
- [x] Добавлен автотест, проверяющий отключение постоянной анимации сотен водных клеток и тяжёлого blur.

## 2. Карта на компьютере

- [x] При ширине экрана от 900 px приложение расширяется до desktop-компоновки.
- [x] Окно карты на экране 1600×900 имеет ширину не менее 700 px и заметно больше мобильного варианта.
- [x] Мобильная компоновка 390×844 не ломается.

## 3. Приказ «Идти»

- [x] У выбранного собственного юнита есть кнопка «Идти».
- [x] После нажатия игрок выбирает конечную клетку на карте.
- [x] Для выбранного юнита виден маршрут с нумерацией шагов и оценкой оставшихся ходов.
- [x] Приказ использует доступные очки движения и сохраняется на следующие ходы.
- [x] Препятствие или движение цели вызывает пересчёт маршрута, а не ошибку.
- [x] Приказ можно отменить.

## 4. Цели маршрута

- [x] Обычная клетка создаёт приказ перемещения.
- [x] Находка создаёт маршрут к находке и по прибытии показывает выбор использования.
- [x] Варвар, вражеский юнит или лагерь создаёт маршрут атаки.
- [x] В начале боя камера центрируется на месте сражения.
- [x] Исчезнувшая цель корректно завершает приказ.

## 5. Рабочий без текстового prompt

- [x] Старая кнопка с текстовым вводом скрыта.
- [x] Приоритет выбирается четырьмя обычными кнопками: баланс, еда, производство, золото.
- [x] Выбор назначает существующий приказ развития города.

## 6. Проверка

- [x] Новые JS-файлы проходят `node --check`.
- [x] Добавлены Playwright-сценарии desktop-карты, маршрута, пересчёта цели, находки, боя и рабочего.
- [x] Ошибки CI разбирались по полным артефактам; исправления объединялись пакетами, а не отправлялись по одному файлу.
- [x] Итоговый отчёт публикуется только после зелёного GitHub Actions; отдельный пустой коммит для отметки не создаётся.

## Граница задачи

В этот блок не входят дороги, транспортные расходы по типам местности, отдельный экран тактического боя, сложная анимация сражения и групповое построение армии. Маршрут использует существующую сетку и один шаг расходует одно очко движения.

## Локальная проверка перед push

- `node --check`: performance, pathing, Playwright spec и service worker — пройдено.
- Изолированный контрактный тест маршрутов: движение на несколько ходов, смена позиции цели, исчезновение цели и штурм лагеря — пройдено.
