# Эпохи: Люди — чек-лист стратегического UX

Статус: конечный объём блока. После выполнения критериев блок закрывается без дополнительной полировки.

## 1. Завершённые маршруты

- [x] Клик по руинам/находке создаёт маршрут именно к объекту.
- [x] По прибытии выбор использования открывается автоматически без дополнительного клика по клетке.
- [x] После выбора находка помечается использованной, приказ завершается.

## 2. Zoom мышью

- [x] Колесо мыши над картой приближает/отдаляет карту.
- [x] Масштабирование привязано к позиции курсора, а не всегда к центру карты.
- [x] Колесо вне карты не перехватывается.

## 3. Визуальная идентичность государств

- [x] Ардена и каждое государство имеют собственный основной цвет и знак.
- [x] Территории читаются по цветным границам влияния.
- [x] Города и юниты получают заметный государственный маркер.
- [x] Названия стран и городов используют разные культурные наборы, а не варианты «Ардан/Ривен».
- [x] В карточке осмотра видно, к какой державе относится иностранный объект.

## 4. Дипломатия v1

- [x] Есть отдельное окно дипломатии.
- [x] Отображаются война / союз / дружественные / нейтральные / враждебные отношения.
- [x] Поддерживаются базовые действия: дар, союз, разрыв союза, мир, объявление войны.
- [x] При игре с тремя ботами один культурно близкий сосед стартует союзником, два других — с отрицательным отношением.
- [x] В выборе числа соперников доступно 3.

## 5. Незавершённые дела

- [x] В верхней панели есть компактные индикаторы отрядов, рабочих, городов и науки.
- [x] Число на ⚔️ показывает отряды с доступным действием без приказа.
- [x] Число на 🔨 показывает рабочих без приказа.
- [x] Число на 🏛️ показывает города с пустой очередью производства.
- [x] 🔬 показывает, что не выбрана технология.
- [x] Повторное нажатие ⚔️/🔨 переключает на следующий подходящий юнит.
- [x] Нажатие 🏛️ переключает между городами с пустой очередью и открывает город.
- [x] Нажатие 🔬 открывает науку.

## 6. Граница задачи

В этот блок не входят сложные договоры, торговля ресурсами по ходам, вассалы, общая война союзников, полноценные культурные модели зданий и юнитов, дипломатический ИИ с памятью на десятки событий и отдельная стратегическая карта отношений.

Цель блока — чтобы государства визуально различались, маршруты ощущались завершёнными, а игрок перед концом хода быстро видел незаконченные действия.
