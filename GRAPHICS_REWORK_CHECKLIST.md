# Эпохи: Люди — чек-лист визуальной демки

Статус: выполнено в ветке `prototype/humans-v1`.

## 1. Авторазведка

- [x] Разведчик с приказом «Авторазведка» использует все доступные очки движения за ход.
- [x] После каждого шага маршрут пересчитывается заново.
- [x] При угрозе, точке интереса или отсутствии безопасного пути приказ останавливается с объяснением.
- [x] Есть автоматический тест на два шага за один ход.

## 2. Режим без тумана войны

- [x] На экране новой партии есть отдельный переключатель «Открытая карта».
- [x] В открытом режиме сразу видны все клетки, города и юниты соперников.
- [x] Режим сохраняется вместе с партией.
- [x] В обычной партии можно однократно открыть карту через меню для тестирования.
- [x] Есть автоматический тест создания открытой партии.

## 3. Биомы и рельеф

- [x] Убраны крупные эмодзи местности из центра клетки.
- [x] Для семи типов местности сделаны отдельные рисованные мини-сцены: равнина, лес, холмы, вода, пустошь, болото, мёртвые земли.
- [x] Клетки получили объёмный край, свет и тень без перехода на тяжёлое 3D.
- [x] Карта остаётся читаемой при отдалении и на экране iPhone.

## 4. Юниты как персонажи

- [x] Разведчик, рабочий, воин, поселенец, копейщик и всадник отображаются рисованными фигурками вместо значков.
- [x] Варвар получил отдельную фигурку.
- [x] Цвет рамки сохраняет различимость государств-соперников.
- [x] Перемещение юнита сопровождается короткой анимацией между клетками.
- [x] Выбранный юнит заметно подсвечен, но не перекрывает карту.

## 5. Находки и объекты мира

- [x] Для восьми точек интереса сделаны отдельные изображения: руины, склад, роща, старая шахта, караван, пещера, башня и храм.
- [x] Точки интереса получили короткие подписи на карте.
- [x] Город, столица и варварский лагерь получили отдельные мини-сцены.
- [x] Ферма, лесозаготовка, шахта, торговый пост и гавань получили отдельные изображения.
- [x] Плодородная земля, руда, самоцветы, рыба и древние руины различаются визуально.

## 6. Интерфейс демки

- [x] Карточка выбранного объекта, панели города и науки приведены к единому тёплому стилю.
- [x] Сага Ардены остаётся доступной и не уменьшает карту на коротком горизонтальном экране.
- [x] Режим открытой карты заметно обозначается в меню и на карте.
- [x] Новая графика не требует тяжёлого движка и работает офлайн.

## 7. Проверка

- [x] Новые JavaScript-файлы прошли синтаксическую проверку.
- [x] Добавлены Playwright-тесты авторазведки, открытой карты, спрайтов и мобильной компоновки.
- [x] Все изменения отправлены одним функциональным коммитом.
- [x] Выполняется один удалённый запуск GitHub Actions; результат фиксируется в итоговом отчёте, чтобы не создавать второй тестовый коммит.

## Граница задачи

На этом этапе не делаются полноценные 3D-модели, сложные боевые анимации, смена времени суток и уникальная анимация каждого здания. Цель — получить приятную, читаемую и характерную 2.5D-демку, после которой имеет смысл продолжать баланс и контент.
